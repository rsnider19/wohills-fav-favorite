## Goal

A themed, runnable `apps/lights` that reads the real local `lights` data through the shared
packages and looks unmistakably like **in-your-face holiday lights**: a night-sky page with a
draped string of C9 bulbs, a neon "HOLIDAY LIGHTS" sign that powers on, a marquee-framed
countdown in dot-matrix bulb digits, a ticker sign, and a lineup of houses framed in chasing
marquee bulbs. It shows every contest phase (before, submissions, voting, closed, results),
the phone sign-in in theme, and empty/loading/error states, with clear slots for M5–M7. Every
effect respects WCAG 2.3.1 (≤ 3 flashes/s), stops under `prefers-reduced-motion` (lights
stay **on**), can be paused from the header (WCAG 2.2.2), keeps text contrast ≥ 4.5:1 and
tap targets ≥ 44 px. The parade and its Vercel deploy are untouched.

## Design system

### Concept

**The page is a front yard at night, and everything on it is a light.** The background is
the sky (deep-blue zenith fading to near-black, falling snow, a warm glow on the horizon). A
draped string of C9 bulbs hangs across the top like a gutter line. The title is a neon sign
that flickers on when you arrive. Countdown digits are a scoreboard of round bulbs inside a
theatre-marquee frame of chasing bulbs, and every house in the lineup hangs in its own
marquee frame. Gold is "lit": buttons are hot gold bulbs, and the house you vote for (M7)
goes fully gold. Nothing is subtle, and nothing strobes.

## Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| Google Fonts slow or blocked: the sign falls back to Arial Black/Impact, digits to a monospace font. | Low | `display=swap` and ordered fallbacks keep it bold and legible; `guards.cjs` checks the fonts load. Self-hosting can come in M8 if needed. |
| Another engine doesn't animate `border-image-source` discretely. | Low | The frame then simply stays lit (frame 0): the safe failure. Chromium verified; Safari and Firefox support discrete animation of non-interpolable properties. |
| `<use href>` inside the frame SVG on very old Safari (< 12.1). | Very low | Bulbs would be missing but the rail still draws; out of the supported range. |
| Motion costs battery on old phones. | Medium | Snow and the swag animate only `transform`/`opacity`; frames repaint at 1.67 Hz; the pause switch and reduced motion stop everything. |
| A later milestone adds an effect that flashes faster. | Medium | `design.test.ts` fails on cycles < 1 s or chases > 2 steps/s in `effects.css`; re-run `flash-probe.cjs` for new effects (Notes). Effects defined elsewhere (e.g. a MapLibre marker CSS file) must be added to the test's input. |
| The dev server reloads a page during the harness (dependency optimization). | Medium | `shoot.cjs` retries once; task 3 warms the server first. |
| picsum.photos unreachable (here) or random photos (elsewhere). | Certain | Fallback art in the app; stand-in photos in the harness. Real photos arrive with M5. |
| `?preview=` misleads someone in production. | Low | Only the signed-in admin can trigger it, and the badge says "Preview". |
| `submitted_by` and phone shown? | None | The footer shows only the signed-in user's own phone; `submitted_by` is read but not displayed (M7 uses it for "Your house"). |

**Rollback:** revert the M4 merge on `main` through a PR. Nothing outside `apps/lights`,
the root scripts/tsconfig/lockfile and docs changes, so the parade and its deploy are
unaffected either way.

````ts
export interface ContestStatus {
  phase: Phase
  /** Mirrors lights.submissions_are_open(): kill switch and window. */
  submissionsOpen: boolean
  /** Mirrors lights.owner_edits_allowed(): submissions open and voting not started. */
  ownerCanEdit: boolean
  votingOpen: boolean
  /** What the hero counts down to, if anything. */
  countdown: { kind: CountdownKind; target: Date } | null
}

const toDate = (iso: string | null) => (iso ? new Date(iso) : null)

/** Pure: the contest phase and countdown for `settings` at `now`. */
export function contestStatus(settings: LightsSettings, now: Date): ContestStatus {
  const vw = votingWindow(settings, now)
  const subsOpenAt = toDate(settings.submissions_open_at)
  const subsCloseAt = toDate(settings.submissions_close_at)
  const submissionsOpen =
    settings.submissions_open && (!subsOpenAt || now >= subsOpenAt) && (!subsCloseAt || now < subsCloseAt)
  const ownerCanEdit = submissionsOpen && vw.opensAt !== null && now < vw.opensAt

  let phase: Phase
  if (settings.results_visible) phase = 'results'
  else if (vw.votingOpen) phase = 'voting'
  else if (vw.beforeOpen) phase = submissionsOpen ? 'submissions' : 'before'
  // After the close, or inside the window with the kill switch off (paused).
  else phase = 'closed'

  let countdown: ContestStatus['countdown'] = null
  if (phase === 'before') {
    if (subsOpenAt && now < subsOpenAt) countdown = { kind: 'entries-open', target: subsOpenAt }
    else if (vw.opensAt) countdown = { kind: 'voting-opens', target: vw.opensAt }
  } else if (phase === 'submissions' && vw.opensAt) {
    countdown = { kind: 'voting-opens', target: vw.opensAt }
  } else if (phase === 'voting' && vw.closesAt) {
    countdown = { kind: 'voting-closes', target: vw.closesAt }
  }

  return { phase, submissionsOpen, ownerCanEdit, votingOpen: vw.votingOpen, countdown }
}

const HOUR = 3_600_000
const DAY = 24 * HOUR

/** Settings that put `anchor` squarely inside `phase`, for the ?preview= override.
 *  Offsets are odd on purpose so the countdown shows every digit position. */
export function previewSettings(phase: Phase, anchor: Date, base: LightsSettings): LightsSettings {
  const at = (ms: number) => new Date(anchor.getTime() + ms).toISOString()
  const windows: Record<Phase, [number, number, number, number]> = {
    //            submissions open, close,      voting opens,          closes
    before: [2 * DAY + 3 * HOUR, 20 * DAY, 12 * DAY, 25 * DAY],
    submissions: [-2 * DAY, 10 * DAY, 5 * DAY + 7 * HOUR + 23 * 60_000, 12 * DAY],
    voting: [-10 * DAY, 2 * DAY, -3 * DAY, 6 * DAY + 11 * HOUR + 42 * 60_000],
    closed: [-20 * DAY, -6 * DAY, -12 * DAY, -HOUR],
    results: [-20 * DAY, -6 * DAY, -12 * DAY, -HOUR],
  }
  const [subsOpen, subsClose, voteOpen, voteClose] = windows[phase]
  return {
    ...base,
    submissions_open: true,
    voting_open: true,
    results_visible: phase === 'results',
    submissions_open_at: at(subsOpen),
    submissions_close_at: at(subsClose),
    voting_opens_at: at(voteOpen),
    voting_closes_at: at(voteClose),
  }
}

/** `?preview=<phase>` from a query string, or null. */
export function parsePreview(search: string): Phase | null {
  const value = new URLSearchParams(search).get('preview')
  return PHASES.find((p) => p === value) ?? null
}
````

````ts
/** Bulb colors, in string order. Each maps to a --color-bulb-* token. */
export const BULB_COLORS = ['red', 'green', 'gold', 'blue', 'magenta', 'white'] as const
export type BulbColor = (typeof BULB_COLORS)[number]

export interface SwagBulb {
  x: number
  y: number
  /** Degrees; bulbs hang off the wire, tilted a little with its slope. */
  angle: number
  color: BulbColor
}

export interface Swag {
  /** SVG path for the wire. */
  wire: string
  bulbs: SwagBulb[]
}

/** A string of lights draped in `swags` scallops across a `width`-wide viewBox.
 *  Each scallop is a quadratic curve from (x0, top) down to `top + sag` and back. */
export function lightString({ width = 1200, swags = 4, perSwag = 7, top = 6, sag = 50 } = {}): Swag {
  const span = width / swags
  const ctrlY = top + 2 * sag // a quadratic's midpoint sits halfway to its control point
  let wire = ''
  const bulbs: SwagBulb[] = []
  for (let s = 0; s < swags; s++) {
    const x0 = s * span
    const x1 = x0 + span
    const xm = (x0 + x1) / 2
    wire += `${s === 0 ? `M ${x0} ${top}` : ''} Q ${xm} ${ctrlY} ${x1} ${top}`
    for (let j = 0; j < perSwag; j++) {
      const t = (j + 0.5) / perSwag
      const u = 1 - t
      const x = u * u * x0 + 2 * u * t * xm + t * t * x1
      const y = u * u * top + 2 * u * t * ctrlY + t * t * top
      const dx = 2 * u * (xm - x0) + 2 * t * (x1 - xm)
      const dy = 2 * u * (ctrlY - top) + 2 * t * (top - ctrlY)
      const slope = (Math.atan2(dy, dx) * 180) / Math.PI
      bulbs.push({
        x: Math.round(x * 10) / 10,
        y: Math.round(y * 10) / 10,
        angle: Math.round(slope * 0.6),
        color: BULB_COLORS[(s * perSwag + j) % BULB_COLORS.length],
      })
    }
  }
  return { wire: wire.trim(), bulbs }
}
````

````ts
const KEY = 'lights-motion'

function stored(): 'on' | 'off' {
  try {
    return localStorage.getItem(KEY) === 'off' ? 'off' : 'on'
  } catch {
    return 'on' // storage blocked (private mode): default to twinkling
  }
}

/** Called once in main.tsx before the first render, so a visitor who paused the lights
 *  never sees the sign flicker on first. */
export function applyStoredMotion() {
  document.documentElement.dataset.motion = stored()
}

/** The header's twinkle switch (WCAG 2.2.2: a way to pause content that moves for more
 *  than 5 seconds). Sets data-motion="off" on <html>; effects.css stops every animation
 *  under it. Remembered per device. Reduced-motion visitors are static either way. */
export function useMotion(): { motionOn: boolean; toggleMotion: () => void } {
  const [motionOn, setMotionOn] = useState(() => document.documentElement.dataset.motion !== 'off')
  const toggleMotion = useCallback(() => {
    setMotionOn((on) => {
      const next = on ? 'off' : 'on'
      document.documentElement.dataset.motion = next
      try {
        localStorage.setItem(KEY, next)
      } catch {
        // Private mode: the switch still works for this visit.
      }
      return !on
    })
  }, [])
  return { motionOn, toggleMotion }
}
````

````ts
function animations(css: string) {
  const out: { decl: string; seconds: number; steps: number | null }[] = []
  for (const m of css.matchAll(/animation:\s*([^;]+);/g)) {
    const decl = m[1].trim()
    if (decl.startsWith('none')) continue
    const seconds = Number(decl.match(/(\d*\.?\d+)s\b/)?.[1])
    const keyframes = decl.split(/\s+/)[0]
    // A step-end chase changes once per keyframe; count the keyframe stops.
    const block = css.match(new RegExp(`@keyframes ${keyframes}\\s*\\{([\\s\\S]*?)\\n\\}`))?.[1] ?? ''
    const steps = /step-end|steps\(/.test(decl) ? (block.match(/\d+%/g)?.length ?? 1) - 1 : null
    out.push({ decl, seconds, steps })
  }
  return out
}
````

### C.3: `flash-probe.cjs` (WCAG 2.3.1 flash probe)

````js
// WCAG 2.3.1 probe: steps every animation on the page through time (Web Animations API),
// screenshots each step, and counts flashes per 6×6 px block.
// A transition is a luminance swing of at least 0.1 (relative luminance) where the darker
// side is below 0.8; a flash is a pair of opposing transitions. Prints the worst block's
// flashes in any 1-second window. Usage: node flash-probe.cjs <baseUrl> [outFile]
// Pure translations (the ticker, the snow) are held at t=0: they move rather than blink,
// which WCAG 2.2.2 covers (the header's pause switch), not 2.3.1.
const { chromium } = require('playwright')
const fs = require('fs')
const [, , BASE = 'http://localhost:5174', OUT] = process.argv
const DT = 50 // ms between samples (20 fps): resolves up to 10 flashes/s
const T = 4800 // ms: two chase cycles, 1.5 twinkle cycles, the whole power-on
const MOVERS = new Set(['marquee', 'snowfall-near', 'snowfall-far'])
const BLOCK = 6

const SCENES = [
  { name: 'phone hero (voting)', vp: { width: 390, height: 844 }, url: '/?preview=voting' },
  { name: 'desktop hero (voting)', vp: { width: 1280, height: 800 }, url: '/?preview=voting' },
  { name: 'desktop gallery, card hovered', vp: { width: 1280, height: 800 }, url: '/?preview=submissions', hover: true },
  { name: 'phone sign-in dialog', vp: { width: 390, height: 844 }, url: '/?preview=submissions&signin' },
]

async function lumaBlocks(decoder, png) {
  return decoder.evaluate(
    async ({ b64, BLOCK }) => {
      const img = await createImageBitmap(await (await fetch('data:image/png;base64,' + b64)).blob())
      const c = new OffscreenCanvas(img.width, img.height)
      const g = c.getContext('2d')
      g.drawImage(img, 0, 0)
      const { data, width, height } = g.getImageData(0, 0, img.width, img.height)
      const lin = (v) => ((v /= 255) <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4)
      const bw = Math.floor(width / BLOCK), bh = Math.floor(height / BLOCK)
      const out = new Array(bw * bh).fill(0)
      for (let y = 0; y < bh * BLOCK; y++)
        for (let x = 0; x < bw * BLOCK; x++) {
          const i = (y * width + x) * 4
          out[Math.floor(y / BLOCK) * bw + Math.floor(x / BLOCK)] +=
            0.2126 * lin(data[i]) + 0.7152 * lin(data[i + 1]) + 0.0722 * lin(data[i + 2])
        }
      return out.map((v) => v / (BLOCK * BLOCK))
    },
    { b64: png.toString('base64'), BLOCK },
  )
}

function worstFlashRate(series, cols) {
  let worst = 0, where = ''
  for (let b = 0; b < series[0].length; b++) {
    const times = []
    let ref = series[0][b], dir = 0
    for (let k = 1; k < series.length; k++) {
      const L = series[k][b]
      if (dir >= 0 && L > ref && dir === 1) ref = L
      else if (dir <= 0 && L < ref && dir === -1) ref = L
      if (L - ref >= 0.1 && Math.min(L, ref) < 0.8) { times.push(k * DT); ref = L; dir = 1 }
      else if (ref - L >= 0.1 && Math.min(L, ref) < 0.8) { times.push(k * DT); ref = L; dir = -1 }
    }
    for (let i = 0; i < times.length; i++) {
      let n = 0
      while (i + n < times.length && times[i + n] < times[i] + 1000) n++
      if (Math.floor(n / 2) > worst) {
        worst = Math.floor(n / 2)
        where = `x≈${(b % cols) * BLOCK}, y≈${Math.floor(b / cols) * BLOCK}`
      }
    }
  }
  return { worst, where }
}

;(async () => {
  const browser = await chromium.launch()
  const decoder = await browser.newPage()
  const lines = []
  for (const scene of SCENES) {
    const ctx = await browser.newContext({ viewport: scene.vp, deviceScaleFactor: 1 })
    const page = await ctx.newPage()
    // Freeze the clock: the countdown's seconds digit would otherwise tick in real time
    // while each sample takes far longer than 50ms, and read as a fast flash.
    await page.clock.setFixedTime(new Date('2026-12-01T22:30:00Z'))
    await page.goto(BASE + scene.url)
    await page.evaluate(() => document.fonts.ready)
    await page.waitForTimeout(800)
    if (scene.hover) {
      await page.evaluate(() => document.querySelector('#houses').scrollIntoView())
      await page.hover('[data-slot="house-card"]')
    }
    const series = []
    const names = new Set()
    for (let t = 0; t <= T; t += DT) {
      const running = await page.evaluate((t) => {
        const anims = document.getAnimations()
        const movers = new Set(['marquee', 'snowfall-near', 'snowfall-far'])
        for (const a of anims) {
          a.pause()
          a.currentTime = movers.has(a.animationName) ? 0 : t
        }
        return anims.map((a) => a.animationName ?? '')
      }, t)
      running.forEach((n) => names.add(n))
      series.push(await lumaBlocks(decoder, await page.screenshot()))
    }
    const { worst, where } = worstFlashRate(series, Math.floor(scene.vp.width / BLOCK))
    const stepped = [...names].filter((n) => n && !MOVERS.has(n)).sort().join(', ')
    const line = `${worst <= 3 ? 'ok  ' : 'FAIL'} ${scene.name}: worst block ${worst} flash(es) in any 1s${where ? ` at ${where}` : ''} (stepped: ${stepped})`
    console.log(line)
    lines.push(line)
    await ctx.close()
  }
  await browser.close()
  if (OUT) fs.writeFileSync(OUT, lines.join('\n') + '\n')
````

````js
// Generates the four chase frames for .bulb-frame: a 144×144 SVG used as a 9-slice
// border-image (slice 24). Corners hold a warm-white bulb; each edge tile holds four
// bulbs (red, green, gold, blue). Frame k shifts every edge one bulb clockwise.
const COLORS = { r: '#ff2d3d', g: '#22ff7a', y: '#ffc21a', b: '#2b8cff', w: '#fff3d6' }
const ORDER = ['r', 'g', 'y', 'b']
const sym = (id, c) =>
  `<g id='${id}'><circle r='10' fill='${c}' fill-opacity='.3'/><circle r='5.5' fill='${c}'/><circle cx='-1.8' cy='-1.8' r='1.7' fill='#fff' fill-opacity='.8'/></g>`
const use = (id, x, y) => `<use href='#${id}' x='${x}' y='${y}'/>`
function frame(k) {
  let s = `<svg xmlns='http://www.w3.org/2000/svg' width='144' height='144' viewBox='0 0 144 144'><defs>`
  for (const [id, c] of Object.entries(COLORS)) s += sym(id, c)
  s += `</defs><rect x='1' y='1' width='142' height='142' rx='7' fill='#0b0e20' stroke='#ffc21a' stroke-opacity='.22' stroke-width='2'/>`
  s += `<rect x='23' y='23' width='98' height='98' fill='none' stroke='#ffc21a' stroke-opacity='.18' stroke-width='2'/>`
  for (const [x, y] of [[12, 12], [132, 12], [12, 132], [132, 132]]) s += use('w', x, y)
  ;[36, 60, 84, 108].forEach((p, i) => {
    const fwd = ORDER[(((i - k) % 4) + 4) % 4] // travels toward +x / +y as k grows
    const back = ORDER[(i + k) % 4] // travels toward -x / -y
    s += use(fwd, p, 12) + use(fwd, 132, p) + use(back, p, 132) + use(back, 12, p)
  })
  return (s + `</svg>`).replaceAll('#', '%23')
}
for (let k = 0; k < 4; k++) console.log(`  --bulb-frame-${k}: url("data:image/svg+xml,${frame(k)}");`)
````
