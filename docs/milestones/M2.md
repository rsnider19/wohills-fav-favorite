## Goal

Create the two internal packages the lights site will be built on, and move the
parade onto them with no visible change:

- **`@wohills/core`** (logic, no styling): Supabase provider and hooks (session, clock,
  polling, settings, voting window, my vote, admin, results, toast, shuffled order,
  secret taps), phone helpers, the photo pipeline, countdown math and the directions link
  builder.
- **`@wohills/ui`** (themed React components plus CSS): the token contract
  (`tokens.css`), shared motion (`motion.css`), `cn()`, `Dialog`, `PhoneAuthDialog`,
  `Countdown`, `Leaderboard`, `Marquee`, `Toaster`, `VoteButton` and `PhotoPicker`. Each
  component has `data-slot` hooks and `className` passthrough.
- The parade uses only semantic token names (`bg`, `surface`, `fg`, `primary`, …). Its
  `App.tsx` becomes mostly composition of shared hooks and components.
- `public.get_results()` returns at most 3 rows (new migration).
- Unit tests (vitest) for the pure functions, and a reproducible screenshot-parity
  harness that proves the parade looks the same pixel for pixel.

## In scope

- `packages/core`, `packages/ui` (source-only, no build step), root `tsconfig.json`
  references, root `npm test` (vitest).
- Everything in plan §3's table except `tools/contest-admin.mjs`, which is M3.
- Converting every parade class name to semantic tokens (paper→bg, card→surface,
  ink→fg, red→primary, cobalt→accent, plus the extra tokens in "Token contract").
- New migration `supabase/migrations/20261112120000_parade_get_results_top3.sql`.
- `supabase/config.toml`: rename `[inbucket]` to `[local_smtp]` so the current Supabase
  CLI can start the local stack (D19).
- `packages/core/README.md` (the "contest contract"), root README updates.
- Parity screenshots committed under `docs/milestones/screenshots/M2/`.

## Out of scope

- **Hosting/DNS (H, on hold).** No Vercel/Cloudflare changes. `vercel.json` is unchanged.
- **Hosted Supabase.** Never touched. The new migration is applied to hosted **later by
  the user** (`supabase db push` from their machine). Until then, hosted `get_results()`
  still returns every row, and the parade keeps its client-side `slice(0, 3)` (D18).
- `apps/lights`, the `lights` schema, `tools/contest-admin.mjs` (M3/M4).
- Removing the admin preview toggle (still marked TEMP; behavior unchanged).
- Component tests in a DOM environment, CI workflows, Playwright as a dependency.
- Any dependency upgrade beyond the additions in D22.

Test files are excluded, or strings in `cn.test.ts` (e.g. `rounded-none`) would emit unused CSS (verified both ways). |
| D5 | How do `@theme` blocks combine across files? | Apps import `tailwindcss`, then `@wohills/ui/tokens.css`, then `@wohills/ui/motion.css`, then declare their own `@theme`. For the same variable, the later declaration wins. **Every token in `tokens.css` lives inside `@theme`, never in a plain `:root {}`.** | Verified: the parade's `--color-surface` and `--countdown-digit-width` override the defaults. `@theme` values are emitted into `@layer theme`. A plain `:root` rule in the package would be unlayered, and unlayered CSS beats layered CSS whatever the order, so an app's `@theme` could never override it. Tailwind only emits theme variables that are used, so unused contract tokens (e.g. `--color-glow` in the parade) cost nothing. Non-namespaced variables such as `--countdown-digit-width` are allowed in `@theme` and used via `w-(--countdown-digit-width)` (verified). |

## Risks and rollback

| Risk | Likelihood | Mitigation |
|---|---|---|
| A subtle visual regression (token value, missing class, text-node split). | Medium | AC7 at 0 px over 24 shots, plus the motion probe. Sensitivity was demonstrated (a 2/255 color change fails). |
| Screenshot noise makes AC7 flaky. | Low | Font cache, software raster, frozen clock, constant `Math.random`, reduced motion. Noise floor measured at 0 px over four runs. If text-edge speckle appears, the font cache wasn't used: check `$S/m2/font-cache` has ~10 files and both runs used it. |
| Google Fonts unreachable from the sandbox. | Low (reachable today) | The cache only needs one successful run. Without it both runs fall back to Georgia/system-ui. That's still a valid parity comparison, just less faithful to the real fonts. |
| GoTrue OTP rate limit (`over_sms_send_rate_limit`). | Low | Per-phone 5 s spacing is built in. If the hourly limit ever hits, wait, or `docker restart supabase_auth_wh-4th-fan-vote` (local only). |
| `tailwind-merge` misclassifies a custom token and drops a class. | Low | Tokens are registered in `cn.ts` and pinned in `cn.test.ts`. Any token added to `tokens.css` must also be added to `cn.ts`. |
| Vercel build differs from local (install, workspaces). | Low | AC6 runs the real Vercel builder offline. The PR's Vercel preview is the gate. |
| A new React-hooks lint rule (v7: `refs`, `set-state-in-effect`, `purity`) rejects a hook. | Verified | The appendix code passes `npm run lint`. Patterns used: refs written only in effects; state set only in async callbacks or derived. |
| Hosted `get_results()` stays un-limited until the user migrates. | Certain, harmless | The parade still slices to 3 in the client (same as production today). The user applies the migration with `supabase db push` when convenient. No agent touches hosted. |
| Lights needs a hook variant that doesn't fit. | Medium | Hooks are parameterized (table/column/fn/columns/initial). Composition (plan §2 escape hatch 3) remains available. |

**Rollback:** revert the M2 merge commit on `main` through a PR. The parade returns to
its M1 code, and the next Vercel build deploys it. The migration only adds `limit 3` and
was never applied to hosted by an agent. Locally, `supabase db reset` after the revert
restores the old function. If the user has already pushed the migration to hosted,
leaving it in place is harmless: the old client sliced to 3 anyway.

```ts
/** Normalize US-style input to E.164 (+1XXXXXXXXXX). */
export function toE164(input: string): string | null {
  const digits = input.replace(/\D/g, '')
  if (digits.length === 10) return `+1${digits}`
  if (digits.length === 11 && digits.startsWith('1')) return `+${digits}`
  return null
}

/** Format US digits as (XXX) XXX-XXXX while typing. A leading 1/+1 is absorbed. */
export function formatPhone(input: string): string {
  let d = input.replace(/\D/g, '')
  if (d.startsWith('1')) d = d.slice(1) // US area codes never start with 1
  d = d.slice(0, 10)
  if (d.length === 0) return ''
  if (d.length < 4) return `(${d}`
  if (d.length < 7) return `(${d.slice(0, 3)}) ${d.slice(3)}`
  return `(${d.slice(0, 3)}) ${d.slice(3, 6)}-${d.slice(6)}`
}
```

### `packages/core/src/shuffle.ts`

```ts
// Seeded 32-bit hash of an entry id (FNV-1a). Combined with a per-session seed
// it gives each entry a well-mixed sort key: the order is random per page
// load, but stable for a given seed so it never reshuffles mid-vote.
export function hashId(id: string, seed: number): number {
  let h = (0x811c9dc5 ^ seed) >>> 0
  for (let i = 0; i < id.length; i++) {
    h ^= id.charCodeAt(i)
    h = Math.imul(h, 0x01000193)
  }
  return h >>> 0
}

/** Returns a new array sorted by hashId(getId(item), seed). If `isPinned`
 *  matches an item, that item moves to the very top. The input is not mutated. */
export function shuffledOrder<T>(
  items: readonly T[],
  seed: number,
  getId: (item: T) => string,
  isPinned?: (item: T) => boolean,
): T[] {
  const sorted = [...items].sort((a, b) => hashId(getId(a), seed) - hashId(getId(b), seed))
  if (isPinned) {
    const idx = sorted.findIndex(isPinned)
    if (idx > 0) sorted.unshift(sorted.splice(idx, 1)[0])
  }
  return sorted
}
```

```ts
import { useMemo, useState } from 'react'
import { shuffledOrder } from './shuffle'

export interface ShuffledOrderOptions<T> {
  /** Stable id used for the hash. Pass a module-level function. */
  getId: (item: T) => string
  /** Key compared with the `?<pinParam>=` value; the match is pinned to the top.
   *  Omit to disable pinning. Pass a module-level function. */
  getPinKey?: (item: T) => string
  /** Query parameter read once at mount. Default 'f'. */
  pinParam?: string
}

/** Randomized order, re-seeded on every page load, stable across re-renders
 *  and polls, with an optional ?f=<key> override that pins one item first. */
export function useShuffledOrder<T>(items: readonly T[], options: ShuffledOrderOptions<T>): T[] {
  const { getId, getPinKey, pinParam = 'f' } = options
  // Random seed picked once per page load so each visitor sees a different order.
  const [seed] = useState(() => Math.floor(Math.random() * 0xffffffff))
  const [pin] = useState(() => new URLSearchParams(window.location.search).get(pinParam)?.trim() || null)
  return useMemo(
    () =>
      shuffledOrder(items, seed, getId, pin && getPinKey ? (item) => getPinKey(item) === pin : undefined),
    [items, seed, getId, getPinKey, pin],
  )
}
```

### `packages/core/src/image.ts`

```ts
import type { AnySupabaseClient } from './context'

/** Decode a photo to something drawable, preferring createImageBitmap but
 *  falling back to an <img> element (more forgiving on mobile Safari). */
export async function decodeImage(file: Blob): Promise<{
  source: CanvasImageSource
  width: number
  height: number
  cleanup: () => void
}> {
  try {
    const bitmap = await createImageBitmap(file)
    return { source: bitmap, width: bitmap.width, height: bitmap.height, cleanup: () => bitmap.close() }
  } catch {
    const objectUrl = URL.createObjectURL(file)
    const img = new Image()
    img.src = objectUrl
    await img.decode()
    if (!img.naturalWidth) {
      URL.revokeObjectURL(objectUrl)
      throw new Error('image decoded empty')
    }
    return {
      source: img,
      width: img.naturalWidth,
      height: img.naturalHeight,
      cleanup: () => URL.revokeObjectURL(objectUrl),
    }
  }
}

/** Identify the real format from magic bytes — file.type lies (iPhones have
 *  handed over HEIC labeled as image/png). */
export async function sniffType(file: Blob): Promise<string> {
  const bytes = new Uint8Array(await file.slice(0, 16).arrayBuffer())
  const ascii = Array.from(bytes, (b) => String.fromCharCode(b)).join('')
  if (bytes[0] === 0xff && bytes[1] === 0xd8) return 'image/jpeg'
  if (bytes[0] === 0x89 && ascii.slice(1, 4) === 'PNG') return 'image/png'
  if (ascii.slice(0, 4) === 'RIFF' && ascii.slice(8, 12) === 'WEBP') return 'image/webp'
  if (ascii.slice(4, 8) === 'ftyp') return 'image/heic'
  return file.type || 'unknown'
}

/** Downscale to maxDim and re-encode as JPEG so phone photos (often huge,
 *  sometimes HEIC) become small files every browser can display. Re-encoding
 *  through a canvas also drops EXIF, including GPS. */
export async function toJpeg(file: Blob, maxDim: number, quality = 0.85): Promise<Blob> {
  const { source, width, height, cleanup } = await decodeImage(file)
  try {
    const scale = Math.min(1, maxDim / Math.max(width, height))
    const canvas = document.createElement('canvas')
    canvas.width = Math.round(width * scale)
    canvas.height = Math.round(height * scale)
    canvas.getContext('2d')!.drawImage(source, 0, 0, canvas.width, canvas.height)
    return await new Promise((resolve, reject) =>
      canvas.toBlob((blob) => (blob ? resolve(blob) : reject(new Error('could not encode image'))), 'image/jpeg', quality),
    )
  } finally {
    cleanup()
  }
}

/** Resize to a JPEG when this browser can decode the photo. If it can't, fall
 *  back to the original, but only if its real bytes (not the self-reported
 *  type) are a format every browser can display. Throws with a user-facing message. */
export async function prepareImageForUpload(
  file: File,
  { maxDim = 1600, maxBytes = 9_000_000 }: { maxDim?: number; maxBytes?: number } = {},
): Promise<{ blob: Blob; contentType: string }> {
  try {
    return { blob: await toJpeg(file, maxDim), contentType: 'image/jpeg' }
  } catch {
    const realType = await sniffType(file)
    if (realType === 'image/heic')
      throw new Error("this is a HEIC photo, which browsers can't show — screenshot it and upload the screenshot")
    if (!/^image\/(jpeg|png|webp)$/.test(realType)) throw new Error('unsupported image format')
    if (file.size > maxBytes) throw new Error('photo too large')
    return { blob: file, contentType: realType }
  }
}

/** Uploads to a public bucket and returns the object's public URL. Use a
 *  unique path per upload so the CDN never serves a stale photo. */
export async function uploadPublicImage(
  client: AnySupabaseClient,
  { bucket, path, blob, contentType }: { bucket: string; path: string; blob: Blob; contentType: string },
): Promise<string> {
  const { error } = await client.storage.from(bucket).upload(path, blob, { contentType })
  if (error) throw error
  return client.storage.from(bucket).getPublicUrl(path).data.publicUrl
}
```

### `packages/core/src/usePolling.ts`

```ts
import { useCallback, useEffect, useRef, useState } from 'react'

export interface Polling<T> {
  /** Last successful result; kept when a later load returns null/undefined (e.g. a network error). */
  data: T | undefined
  /** True until the first load settles. */
  loading: boolean
  refresh: () => Promise<void>
}

/** Runs `load` right after mount and then every `intervalMs` while `enabled`. */
export function usePolling<T>(
  load: () => Promise<T | null | undefined>,
  { intervalMs = 30_000, enabled = true }: { intervalMs?: number; enabled?: boolean } = {},
): Polling<T> {
  const [data, setData] = useState<T | undefined>(undefined)
  const [loading, setLoading] = useState(true)
  // Always call the latest `load` without restarting the timers on every render.
  const loadRef = useRef(load)
  useEffect(() => {
    loadRef.current = load
  })
  const refresh = useCallback(async () => {
    try {
      const next = await loadRef.current()
      if (next !== null && next !== undefined) setData(next)
    } catch (err) {
      console.error(err)
    } finally {
      setLoading(false)
    }
  }, [])
  useEffect(() => {
    if (!enabled) return
    // Deferred so the first state update happens outside the effect body.
    const first = setTimeout(refresh, 0)
    const interval = setInterval(refresh, intervalMs)
    return () => {
      clearTimeout(first)
      clearInterval(interval)
    }
  }, [refresh, intervalMs, enabled])
  return { data, loading, refresh }
}
```

```ts
import { useCallback, useEffect, useState } from 'react'
import type { PostgrestError, Session } from '@supabase/supabase-js'
import { useSupabase } from './useSupabase'

export interface MyVoteOptions {
  /** Column holding the voted-for id: 'entry_id' (parade) or 'house_id' (lights). */
  column: string
  /** Default 'votes' (resolved in the client's schema). */
  table?: string
  /** Skip fetching while true, e.g. while a vote chosen before sign-in is still being applied. */
  paused?: boolean
}

/** The signed-in user's current vote, plus `vote()` to cast or change it. */
export function useMyVote(
  session: Session | null,
  { column, table = 'votes', paused = false }: MyVoteOptions,
): { myVote: string | null; vote: (targetId: string) => Promise<{ error: PostgrestError | null }> } {
  const client = useSupabase()
  const userId = session?.user.id ?? null
  // Tagged with the user it belongs to, so a sign-out or account switch never shows a stale pick.
  const [fetched, setFetched] = useState<{ userId: string; id: string | null } | null>(null)

  useEffect(() => {
    if (!userId || paused) return
    let cancelled = false
    client
      .from(table)
      .select(column)
      .maybeSingle<Record<string, string | null>>()
      .then(({ data }) => {
        if (!cancelled) setFetched({ userId, id: data?.[column] ?? null })
      })
    return () => {
      cancelled = true
    }
  }, [client, table, column, userId, paused])

  const vote = useCallback(
    async (targetId: string) => {
      if (!userId) throw new Error('vote() needs a signed-in session')
      // The PK on votes.user_id makes this an insert-or-change-my-vote, never a second vote.
      const { error } = await client
        .from(table)
        .upsert({ user_id: userId, [column]: targetId }, { onConflict: 'user_id' })
      if (!error) setFetched({ userId, id: targetId })
      return { error }
    },
    [client, table, column, userId],
  )

  const myVote = userId && fetched?.userId === userId ? fetched.id : null
  return { myVote, vote }
}
```

```ts
/** Returns a tap handler that calls `onTrigger` after `count` taps, each within
 *  `windowMs` of the previous one. Used for the hidden admin sign-in. */
export function useSecretTaps(onTrigger: () => void, { count = 5, windowMs = 1500 } = {}): () => void {
  const taps = useRef({ count: 0, timer: 0 })
  // Latest callback without re-creating the handler (refs may only be written outside render).
  const trigger = useRef(onTrigger)
  useEffect(() => {
    trigger.current = onTrigger
  })

  return useCallback(() => {

    window.clearTimeout(t.timer)
    t.count += 1
    if (t.count >= count) {
      t.count = 0
      trigger.current()
      return
    }
    t.timer = window.setTimeout(() => {
      t.count = 0
    }, windowMs)
  }, [count, windowMs])
}
```

```tsx
import { useRef, useState, type FormEvent, type ReactNode } from 'react'
import { formatPhone, toE164, useSupabase } from '@wohills/core'
import { cn } from './cn'
import { Dialog } from './Dialog'
import { DEFAULT_PHONE_AUTH_LABELS, type PhoneAuthLabels } from './labels'

export interface PhoneAuthDialogProps {
  onSuccess: () => void
  onCancel: () => void
  /** Extra line under the title on the phone step (e.g. which vote is pending). */
  notice?: ReactNode
  labels?: Partial<PhoneAuthLabels>
  className?: string
}

const inputClass =
  'w-full rounded-field border border-fg/20 bg-field px-4 py-3 text-fg outline-none focus:border-fg'
const submitClass =
  'w-full rounded-full bg-fg px-4 py-3 font-semibold text-bg transition hover:bg-primary disabled:opacity-50'

/** Two-step SMS sign-in (phone → 6-digit code) against the provider's Supabase client. */
export function PhoneAuthDialog({ onSuccess, onCancel, notice, labels, className }: PhoneAuthDialogProps) {
  const l = { ...DEFAULT_PHONE_AUTH_LABELS, ...labels }
  const supabase = useSupabase()
  const [step, setStep] = useState<'phone' | 'code'>('phone')
  const [phoneInput, setPhoneInput] = useState('')
  const [phone, setPhone] = useState('')
  const [code, setCode] = useState('')
  const [busy, setBusy] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const codeRef = useRef<HTMLInputElement>(null)

  async function sendCode(e: FormEvent) {
    e.preventDefault()
    setError(null)
    const e164 = toE164(phoneInput)
    if (!e164) {
      setError(l.invalidPhone)
      return
    }
    setBusy(true)
    const { error } = await supabase.auth.signInWithOtp({ phone: e164 })
    setBusy(false)
    if (error) {
      setError(error.message)
      return
    }
    setPhone(e164)
    setStep('code')
    setTimeout(() => codeRef.current?.focus(), 50)
  }

  async function verifyCode(e: FormEvent) {
    e.preventDefault()
    setError(null)
    if (!/^\d{6}$/.test(code)) {
      setError(l.invalidCode)
      return
    }
    setBusy(true)
    const { error } = await supabase.auth.verifyOtp({ phone, token: code, type: 'sms' })
    setBusy(false)
    if (error) {
      setError(error.message)
      return
    }
    onSuccess()
  }

  return (
    <Dialog onClose={onCancel} label={l.dialogLabel} className={className}>
      <div className="mb-6" data-slot="auth-header">
        <p data-slot="auth-eyebrow" className="mb-2 text-xs font-semibold tracking-[0.25em] text-primary uppercase">
          {step === 'phone' ? l.phoneEyebrow : l.codeEyebrow}
        </p>
        <h2 data-slot="auth-title" className="font-display text-3xl font-semibold">
          {step === 'phone' ? l.phoneTitle : l.codeTitle}
        </h2>
        {step === 'phone' && notice && (
          <p data-slot="auth-notice" className="mt-2 text-sm font-medium text-primary">
            {notice}
          </p>
        )}
        <p data-slot="auth-help" className="mt-2 text-sm leading-relaxed text-fg/60">
          {step === 'phone' ? l.phoneHelp : l.codeHelp(phone)}
        </p>
      </div>

      {step === 'phone' ? (
        <form onSubmit={sendCode} className="space-y-4">
          <input
            data-slot="auth-phone-input"
            type="tel"
            autoComplete="tel"
            inputMode="tel"
            placeholder={l.phonePlaceholder}
            value={phoneInput}
            onChange={(e) => {
              const raw = e.target.value
              // Reformat when adding; accept deletions as-is so backspacing
              // over ")" or "-" doesn't get stuck re-inserting it.
              setPhoneInput(raw.length > phoneInput.length ? formatPhone(raw) : raw)
            }}
            autoFocus
            className={cn(inputClass, 'text-lg')}
          />
          <button data-slot="auth-submit" type="submit" disabled={busy} className={submitClass}>
            {busy ? l.sending : l.send}
          </button>
        </form>
      ) : (
        <form onSubmit={verifyCode} className="space-y-4">
          <input
            data-slot="auth-code-input"
            ref={codeRef}
            type="text"
            autoComplete="one-time-code"
            inputMode="numeric"
            maxLength={6}
            placeholder="••••••"
            value={code}
            onChange={(e) => setCode(e.target.value.replace(/\D/g, ''))}
            className={cn(inputClass, 'text-center font-display text-3xl tracking-[0.5em]')}
          />
          <button data-slot="auth-submit" type="submit" disabled={busy} className={submitClass}>
            {busy ? l.verifying : l.verify}
          </button>
          <button
            data-slot="auth-change-number"
            type="button"
            onClick={() => {
              setStep('phone')
              setCode('')
              setError(null)
            }}
            className="w-full text-sm text-fg/55 underline-offset-4 hover:underline"
          >
            {l.changeNumber}
          </button>
        </form>
      )}

      {error && (
        <p data-slot="auth-error" className="mt-4 rounded-lg bg-primary/10 px-3 py-2 text-sm text-danger">
          {error}
        </p>
      )}
    </Dialog>
  )
}
```

```tsx
import { countdownSegments, type CountdownSegment } from '@wohills/core'

export interface CountdownProps {
  /** e.g. "Voting opens in". Also the start of the timer's aria-label. */
  label: string
  target: Date
  now: Date
  /** Decoration rendered before the visible label only (parade: "★ "). */
  labelPrefix?: string
  unitLabels?: Partial<Record<CountdownSegment['unit'], string>>
  className?: string
}

/** Days/hours/min/sec until `target`. Digits sit in fixed-width slots
 *  (--countdown-digit-width) so the timer never shifts as numbers change. */
export function Countdown({ label, target, now, labelPrefix = '', unitLabels, className }: CountdownProps) {
  const segments = countdownSegments(target, now)
  return (
    <div data-slot="countdown" className={className}>
      <p data-slot="countdown-label" className="mb-3 text-xs font-semibold tracking-[0.25em] text-primary uppercase">
        {labelPrefix}
        {label}
      </p>
      <div
        data-slot="countdown-timer"
        className="flex divide-x divide-fg/15 rounded-card border border-fg/15 bg-surface"
        role="timer"
        aria-label={`${label}: ${segments.map((s) => `${s.value} ${s.unit}`).join(', ')}`}
      >
        {segments.map((seg) => (
          <div key={seg.unit} data-slot="countdown-segment" className="flex-1 px-4 py-4 text-center sm:px-6 sm:py-5">
            <div data-slot="countdown-value" className="font-display text-3xl font-semibold text-fg sm:text-5xl">
              {String(seg.value)
                .padStart(2, '0')
                .split('')
                .map((digit, i) => (
                  <span key={i} data-slot="countdown-digit" className="inline-block w-(--countdown-digit-width) text-center">
                    {digit}
                  </span>
                ))}
            </div>
            <div data-slot="countdown-unit" className="mt-1 text-[10px] font-semibold tracking-[0.2em] text-fg/45 uppercase">
              {unitLabels?.[seg.unit] ?? seg.unit}
            </div>
          </div>
        ))}
      </div>
    </div>
  )
}
```

```tsx
import { useCallback, useEffect, useState } from 'react'
import {
  useContestSettings,
  useIsAdmin,
  useMyVote,
  useNow,
  usePolling,
  useResults,
  useSecretTaps,
  useSession,
  useShuffledOrder,
  useToast,
  useVotingWindow,
  type WindowPreview,
} from '@wohills/core'
import { Countdown, Leaderboard, Marquee, PhoneAuthDialog, Toaster } from '@wohills/ui'
import { supabase } from './lib/supabase'
import type { Entry, ResultRow } from './types'
import { AUTH_LABELS, TICKER } from './copy'
import badge from './assets/dynamic-duos-badge.png'
import EntryCard from './components/EntryCard'

// Module-level so useShuffledOrder's memo stays stable across renders.
const entryId = (e: Entry) => e.id
const entryNumber = (e: Entry) => String(e.entry_number)

async function loadEntries() {
  return (await supabase.from('entries').select('*').order('entry_number')).data as Entry[] | null
}

export default function App() {
  const { session } = useSession()
  const now = useNow()
  const { settings, loading: settingsLoading, refresh: refreshSettings } = useContestSettings()
  const { data: entries = [], loading: entriesLoading, refresh: refreshEntries } = usePolling(loadEntries)
  const { results, refresh: refreshResults } = useResults<ResultRow>(settings.results_visible)
  const loading = settingsLoading || entriesLoading
  const isAdmin = useIsAdmin(session)
  const { toast, flash } = useToast()

  // Secret pre-voting sign-in (for the admin to upload photos): visiting
  // /?signin opens the modal, as do 5 quick taps on the header badge.
  // Harmless if discovered — voting outside the window is still blocked by RLS.
  const [showAuth, setShowAuth] = useState(() => new URLSearchParams(window.location.search).has('signin'))
  const onSecretTap = useSecretTaps(() => setShowAuth(true))
  const [pendingVote, setPendingVote] = useState<Entry | null>(null)
  const [voteBusy, setVoteBusy] = useState(false)
  const { myVote, vote } = useMyVote(session, { column: 'entry_id', paused: pendingVote !== null })
  // TEMP: header toggle to preview pre-vote vs. live-voting UI without touching
  // the database. null = use real settings/clock. Remove when done previewing.
  const [previewMode, setPreviewMode] = useState<WindowPreview>(null)

  // The window is enforced server-side by RLS against the database clock;
  // this clock only drives the countdown display and button states.
  const { opensAt, closesAt, beforeOpen, afterClose, votingOpen } = useVotingWindow(settings, now, previewMode)

  const refreshAll = useCallback(() => {
    refreshSettings()
    refreshEntries()
    refreshResults()
  }, [refreshSettings, refreshEntries, refreshResults])

  // Re-fetch the moment a window boundary passes so the UI flips immediately
  // instead of waiting out the 30-second poll.
  useEffect(() => {
    if (loading) return
    const t = setTimeout(refreshAll, 0)
    return () => clearTimeout(t)
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [beforeOpen, afterClose])

  const submitVote = useCallback(
    async (entry: Entry, previous: string | null) => {
      const { error } = await vote(entry.id)
      if (error) {
        flash('Could not save your vote — voting may be closed.')
        return
      }
      flash(
        previous
          ? `Vote changed to ${entry.theme || entry.street} ★`
          : `Vote cast for ${entry.theme || entry.street} ★`,
      )
    },
    [vote, flash],
  )

  // Apply the vote that opened the sign-in modal once auth completes.
  useEffect(() => {
    if (!session || !pendingVote) return
    const entry = pendingVote
    ;(async () => {
      await submitVote(entry, null)
      setPendingVote(null)
    })()
  }, [session, pendingVote, submitVote])

  async function castVote(entry: Entry) {
    if (!votingOpen) return
    if (!session) {
      setPendingVote(entry)
      setShowAuth(true)
      return
    }
    if (entry.id === myVote) return
    setVoteBusy(true)
    await submitVote(entry, myVote)
    setVoteBusy(false)
  }

  // Ballot order: randomized so no float gets a positional advantage, with an
  // optional ?f=<entry number> override that floats one entry to the very top.
  const orderedEntries = useShuffledOrder(entries, { getId: entryId, getPinKey: entryNumber })

  return (
    <div className="min-h-screen">
      {/* Header */}
      <header className="mx-auto flex w-full max-w-6xl items-center justify-between px-5 pt-6">
        <div
          className="rise inline-block text-xs font-semibold tracking-[0.2em] text-fg/50 uppercase select-none"
          onClick={onSecretTap}
        >
          Worthington Hills Parade
        </div>
        {/* TEMP: admin-only preview toggle — remove before launch */}
        {isAdmin && (
          <button
            type="button"
            onClick={() =>
              setPreviewMode((m) => (m === null ? 'prevote' : m === 'prevote' ? 'live' : null))
            }
            className="rounded-full border border-fg/20 bg-surface px-3 py-1 text-[0.65rem] font-semibold tracking-[0.15em] text-fg/60 uppercase"
          >
            {previewMode === 'prevote'
              ? 'Preview: Pre-Vote'
              : previewMode === 'live'
                ? 'Preview: Live'
                : 'Preview: Live Settings'}
          </button>
        )}
      </header>

      {/* Hero */}
      <section className="mx-auto w-full max-w-6xl px-5 pt-14 pb-14 sm:pt-20">
        <p
          className="rise mb-5 text-xs font-semibold tracking-[0.25em] text-primary uppercase"
          style={{ animationDelay: '0.05s' }}
        >
          July 4th, 2026 ✦ Fan Favorite Ballot
        </p>
        <h1 className="sr-only">Worthington Hills Dynamic Duos</h1>
        <div className="flex flex-col items-center gap-10 lg:flex-row lg:items-center lg:gap-12">
          <div className="w-full lg:w-1/2">
            <img
              src={badge}
              alt="Worthington Hills Dynamic Duos 2026 — America's Semiquincentennial"
              className="rise mx-auto w-full max-w-xs sm:max-w-sm"
              style={{ animationDelay: '0.12s' }}
            />
          </div>
          <div className="w-full lg:w-1/2">
            {!loading && beforeOpen && opensAt && (
              <div className="rise" style={{ animationDelay: '0.28s' }}>
                <Countdown label="Voting opens in" labelPrefix="★ " target={opensAt} now={now} />
              </div>
            )}
            {!loading && votingOpen && closesAt && (
              <div className="rise" style={{ animationDelay: '0.28s' }}>
                <Countdown label="Voting closes in" labelPrefix="★ " target={closesAt} now={now} />
              </div>
            )}
          </div>
        </div>
        {!loading && !votingOpen && !beforeOpen && !settings.results_visible && (
          <div className="rise mt-8 inline-block rounded-xl border border-fg/15 bg-surface px-5 py-3 text-sm text-fg/70">
            Voting is closed. Results will be announced soon — stay tuned.
          </div>
        )}
      </section>
```

```sql
-- get_results() used to return every entry's tally once results_visible was
-- flipped; the client then showed only the top 3. Anyone calling the RPC
-- directly could read the full standings. Limit it to the top 3 in SQL.
-- Same signature and ordering as 20260612000000_floats.sql, so
-- `create or replace` keeps the existing grants.
create or replace function public.get_results()
returns table (
  entry_id uuid,
  entry_number int,
  theme text,
  street text,
  emoji text,
  image_url text,
  vote_count bigint
)
language sql
security definer
set search_path = public
stable
as $$
  select e.id, e.entry_number, e.theme, e.street, e.emoji, e.image_url,
         count(v.user_id) as vote_count
  from public.entries e
  left join public.votes v on v.entry_id = e.id
  where (select results_visible from public.settings)
  group by e.id
  order by vote_count desc, e.entry_number
  limit 3;
$$;
```

```js
const path = require('node:path')

async function rest(method, route, body, token = SERVICE) {
  const res = await fetch(`${API}/rest/v1/${route}`, {
    method,
    headers: {
      apikey: token === SERVICE ? SERVICE : ANON,
      Authorization: `Bearer ${token}`,
      'Content-Type': 'application/json',
      Prefer: 'return=representation,resolution=merge-duplicates',
    },
    body: body ? JSON.stringify(body) : undefined,
  })
  const text = await res.text()
  if (!res.ok) throw new Error(`${method} ${route} -> ${res.status} ${text}`)
  return text ? JSON.parse(text) : null
}

// Sessions for the non-UI users come from a password grant, not an SMS code, so a
// run only spends one OTP per viewport (GoTrue allows one OTP per phone per 5s
// and rate-limits SMS per hour, test numbers included).
async function ensureSession(phone) {
  const admin = { apikey: SERVICE, Authorization: `Bearer ${SERVICE}`, 'Content-Type': 'application/json' }
  const password = `parity-${phone}`
  const list = await (await fetch(`${API}/auth/v1/admin/users?per_page=1000`, { headers: admin })).json()
  const user = list.users.find((u) => u.phone === `1${phone}`)
  const res = user
    ? await fetch(`${API}/auth/v1/admin/users/${user.id}`, { method: 'PUT', headers: admin, body: JSON.stringify({ password }) })
    : await fetch(`${API}/auth/v1/admin/users`, { method: 'POST', headers: admin, body: JSON.stringify({ phone: `1${phone}`, password, phone_confirm: true }) })
  if (!res.ok) throw new Error(`admin user ${res.status} ${await res.text()}`)
  const tok = await fetch(`${API}/auth/v1/token?grant_type=password`, {
    method: 'POST', headers: { apikey: ANON, 'Content-Type': 'application/json' },
    body: JSON.stringify({ phone: `1${phone}`, password }),
  })
  if (!tok.ok) throw new Error(`password grant ${tok.status} ${await tok.text()}`)
  return tok.json() // full session: access_token, refresh_token, expires_at, user
}

const iso = (ms) => new Date(ms).toISOString()
async function setWindow(t0, kind, extra = {}) {
  const w = {
    prevote: { voting_opens_at: iso(t0 + sec(3 * 86400 + 4 * 3600 + 5 * 60 + 6)), voting_closes_at: iso(t0 + sec(5 * 86400)) },
    live: { voting_opens_at: iso(t0 - sec(3600)), voting_closes_at: iso(t0 + sec(86400 + 2 * 3600 + 3 * 60 + 4)) },
    closed: { voting_opens_at: iso(t0 - sec(7200)), voting_closes_at: iso(t0 - sec(3600)) },
  }[kind]
  await rest('PATCH', 'settings?id=eq.true', { voting_open: true, results_visible: false, ...w, ...extra })
}

async function resetFixture() {

// Google Fonts may hand out different font builds from run to run, which shifts
// glyph antialiasing. Cache every font response on disk the first time and
// replay it afterwards, so the before and after runs use identical bytes.
const FONT_CACHE = process.env.PARITY_FONT_CACHE ?? path.join(__dirname, 'font-cache')
async function routeFonts(ctx) {
  fs.mkdirSync(FONT_CACHE, { recursive: true })
  await ctx.route(/^https:\/\/fonts\.(googleapis|gstatic)\.com\//, async (route) => {
    const key = require('node:crypto').createHash('sha256').update(route.request().url()).digest('hex')
    const file = path.join(FONT_CACHE, key)
    if (!fs.existsSync(file)) {
      const res = await route.fetch()
      fs.writeFileSync(file, await res.body())
      fs.writeFileSync(`${file}.type`, res.headers()['content-type'] ?? 'application/octet-stream')
    }
    await route.fulfill({
      body: fs.readFileSync(file),
      contentType: fs.readFileSync(`${file}.type`, 'utf8'),
      headers: { 'access-control-allow-origin': '*' },
    })
  })
}

async function newPage(browser, vp, t0) {
  const ctx = await browser.newContext({ viewport: VIEWPORTS[vp], deviceScaleFactor: 1, reducedMotion: 'reduce' })
  await routeFonts(ctx)
  // Constant Math.random → constant shuffle seed, however often it is called.
  await ctx.addInitScript(() => { Math.random = () => 0.5 })
  const page = await ctx.newPage()
  await page.clock.setFixedTime(new Date(t0))
  return { ctx, page }
}

async function settle(page) {
  await page.waitForLoadState('networkidle')
  await page.evaluate(async () => {
    for (const img of document.images) img.loading = 'eager'
    await Promise.all([...document.images].map((i) => i.decode().catch(() => {})))
    // fonts.ready only covers loads already started; request every face the
    // parade uses so a late swap from the fallback can't land mid-screenshot.
    const faces = ['300', '400', '600', '700', 'italic 300', 'italic 400']
      .flatMap((w) => [`${w} 16px Fraunces`, `${w} 16px Archivo`])
    await Promise.all(faces.map((f) => document.fonts.load(f)))
    await document.fonts.ready
  })
  await page.waitForTimeout(400)
}

}

async function motionProbe(browser, url) {
  // Normal-motion context: the keyframe names/durations must survive the move to motion.css.
  const out = {}
  for (const reduced of ['no-preference', 'reduce']) {
    const ctx = await browser.newContext({ reducedMotion: reduced })
    const page = await ctx.newPage()
    await page.goto(url)
    await page.waitForSelector('.marquee-track')
    out[reduced] = await page.evaluate(() =>
      ['.rise', '.marquee-track'].map((sel) => {

        return `${sel}: ${s.animationName} ${s.animationDuration} ${s.animationTimingFunction} ${s.animationIterationCount}`
      }),
    )
    await ctx.close()
  }
  return out
}

// Pixel diff in Chromium itself (no image libraries needed). A pixel counts as
// different when any RGBA channel differs by more than CHANNEL_TOLERANCE (out of
// 255). 1 absorbs the rare off-by-one rasterization of a focused input's rounded
// border; any real token or layout change moves far more than that.
const CHANNEL_TOLERANCE = 1
const MAX_DIFF_RATIO = 0
async function diff(beforeDir, afterDir, diffDir) {
  fs.mkdirSync(diffDir, { recursive: true })
  const names = fs.readdirSync(beforeDir).filter((f) => f.endsWith('.png')).sort()
  const afterNames = fs.readdirSync(afterDir).filter((f) => f.endsWith('.png')).sort()
  let failed = names.join() !== afterNames.join()
  if (failed) console.log(`FAIL file sets differ:\n  before: ${names.join(' ')}\n  after:  ${afterNames.join(' ')}`)
  const browser = await chromium.launch()
  const page = await browser.newPage()
  for (const name of names.filter((n) => afterNames.includes(n))) {
    const toUrl = (p) => `data:image/png;base64,${fs.readFileSync(p).toString('base64')}`
    const r = await page.evaluate(async ([u1, u2, tol]) => {
      const load = (u) => new Promise((res, rej) => { const i = new Image(); i.onload = () => res(i); i.onerror = rej; i.src = u })
      const [i1, i2] = await Promise.all([load(u1), load(u2)])
      if (i1.width !== i2.width || i1.height !== i2.height)
        return { size: `${i1.width}x${i1.height} vs ${i2.width}x${i2.height}` }
      const read = (img) => {
        const cv = new OffscreenCanvas(img.width, img.height)
        const cx = cv.getContext('2d')
        cx.drawImage(img, 0, 0)
        return cx.getImageData(0, 0, img.width, img.height)
      }
      const d1 = read(i1).data, d2 = read(i2)
      const out = new OffscreenCanvas(i1.width, i1.height)
      const oc = out.getContext('2d')
      const od = oc.createImageData(i1.width, i1.height)
      let diffPx = 0
      for (let p = 0; p < d1.length; p += 4) {
        const delta = Math.max(...[0, 1, 2, 3].map((k) => Math.abs(d1[p + k] - d2.data[p + k])))
        const bad = delta > tol
        if (bad) diffPx++
        // Diff image: changed pixels red, unchanged pixels faded.
        od.data[p] = bad ? 255 : d1[p] * 0.2 + 204
        od.data[p + 1] = bad ? 0 : d1[p + 1] * 0.2 + 204
        od.data[p + 2] = bad ? 0 : d1[p + 2] * 0.2 + 204
        od.data[p + 3] = 255
      }
      oc.putImageData(od, 0, 0)
      const blob = await out.convertToBlob({ type: 'image/png' })
      const buf = new Uint8Array(await blob.arrayBuffer())
      let bin = ''
      for (let k = 0; k < buf.length; k += 0x8000) bin += String.fromCharCode(...buf.subarray(k, k + 0x8000))
      return { total: d1.length / 4, diffPx, png: diffPx ? btoa(bin) : null }
    }, [toUrl(path.join(beforeDir, name)), toUrl(path.join(afterDir, name)), CHANNEL_TOLERANCE])
    if (r.size) { failed = true; console.log(`FAIL ${name} size ${r.size}`); continue }
    const ratio = r.diffPx / r.total
    const bad = ratio > MAX_DIFF_RATIO
    if (bad) failed = true
    if (r.png) fs.writeFileSync(path.join(diffDir, name), Buffer.from(r.png, 'base64'))
    console.log(`${bad ? 'FAIL' : 'ok  '} ${name} ${r.diffPx} px differ (${(ratio * 100).toFixed(4)}%)`)
  }
  await browser.close()
  const m1 = fs.readFileSync(path.join(beforeDir, 'motion.json'), 'utf8')
  const m2 = fs.readFileSync(path.join(afterDir, 'motion.json'), 'utf8')
  if (m1 !== m2) { failed = true; console.log(`FAIL motion.json differs\n${m1}\n---\n${m2}`) }
  else console.log('ok   motion.json identical')
  console.log(failed ? 'PARITY FAIL' : 'PARITY OK')
  process.exit(failed ? 1 : 0)
}

if (cmd === 'shoot') shoot(a, b, c).catch((e) => { console.error(e); process.exit(1) })
else if (cmd === 'diff') diff(a, b, c).catch((e) => { console.error(e); process.exit(1) })
else { console.error('usage: parity.cjs shoot <url> <outDir> [jpegDir] | diff <before> <after> <diffDir>'); process.exit(2) }
```

````markdown
# @wohills/core

Logic shared by the Worthington Hills contest sites: the Supabase provider and hooks,
phone helpers, the photo pipeline, countdown math and the directions link builder. No
styling; themed components live in `@wohills/ui`.

This is an internal, source-only package. It has no build step: each app's Vite compiles
`src/` directly. Import only from `@wohills/core` (the `src/index.ts` barrel).

## Using it

```tsx
import { createClient } from '@supabase/supabase-js'
import { SupabaseProvider } from '@wohills/core'

// Parade: default `public` schema. Lights: its own schema in the same project.
const supabase = createClient(url, anonKey, { db: { schema: 'lights' } })

createRoot(root).render(
  <SupabaseProvider client={supabase}>
    <App />
  </SupabaseProvider>,
)
```

Every hook reads the client from the provider, so table and function names resolve in
the client's schema. The exception is `useIsAdmin()`, which always calls
`public.is_admin()`, because both contests share one admin.

## The contest contract

A contest is a Postgres schema with these objects. The hooks rely on them, and the
database (not the client) enforces every fairness rule.

| Object | Shape | Rules | Used by |
|---|---|---|---|
| `settings` | one row: `voting_open boolean`, `results_visible boolean`, `voting_opens_at timestamptz null`, `voting_closes_at timestamptz null`, plus contest-specific columns | readable by `anon`/`authenticated`; writable only with the service role | `useContestSettings`, `votingWindow` |
| `voting_is_open()` | `boolean`: kill switch AND `now()` inside the window (database clock) | used inside the `votes` RLS policies | (RLS) |
| `votes` | `user_id uuid primary key references auth.users`, `<target>_id uuid` (`entry_id` / `house_id`), `created_at`, `updated_at` | select own row only; insert/update own row only while `voting_is_open()`; the PK makes a second vote impossible (upsert changes it) | `useMyVote` |
| `get_results()` | `security definer`; returns no rows unless `results_visible`; at most **3** rows ordered by vote count desc, then a stable tiebreak | the only way to read tallies | `useResults` |
| `public.is_admin()` | `boolean`: JWT phone = `public.admin_config.admin_phone` | shared by every contest | `useIsAdmin` |

Client clocks and countdowns are display only. Parade: `public` schema, target
`entries` / `entry_id`. Lights (M3): `lights` schema, target `houses` / `house_id`, plus
its own rules (only approved houses, no self-votes, submission window).
````
