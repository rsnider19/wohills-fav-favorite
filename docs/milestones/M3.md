## Goal

The complete backend for the holiday lights contest, inside the shared Supabase project,
with every fairness rule enforced by the database and covered by tests:

- A `lights` Postgres schema (exposed to the API) with `settings`, `houses`, `votes`,
  RLS, triggers, window helpers and `get_results()` (top 3 with counts and rank).
- A public `houses` storage bucket with per-owner folder policies tied to the windows.
- A geofence drafted from public map data, **for the user to confirm**, stored in
  `lights.settings`.
- A `geocode` Edge Function (US Census Geocoder) with a geofence re-check.
- `tools/contest-admin.mjs --contest parade|lights`, replacing the parade's
  `set-voting-window.mjs` while keeping `npm run set-window` working.
- A local seed for lights, pgTAP tests for every rule, unit tests for the function's
  logic, and an end-to-end smoke script, all against the local stack only.
- No change to the parade's behavior or data.

### Geofence (for the user to confirm)

| | min | max |
|---|---|---|
| Latitude | **40.1175** | **40.1450** |
| Longitude | **−83.0670** | **−83.0305** |

Roughly 3.1 km north–south by 3.1 km east–west, centered just east of the Worthington
Hills Country Club (Columbus, OH 43235).

How it was derived:

1. **OpenStreetMap** (Nominatim and Overpass, © OpenStreetMap contributors, ODbL). The
   `Worthington Hills` place node (GNIS 1059961) is at 40.12867, −83.04324, and Nominatim
   files the Worthington Hills Country Club (40.12674, −83.05321) under the "Worthington
   Hills" area. The parade's six streets map to OSM ways: Candlewood Dr/Ln
   (40.1223–40.1242), Mission Hills Ln (40.1265–40.1271, east end −83.0385), Blind Brook
   Dr/Ct (40.1293–40.1312), Shelley Ct + Tennyson Ct (40.1325–40.1334, west end
   −83.0610), Newcomer Rd + Copperfield Dr + Markhaven Dr ("NewCopperMark",
   40.1323–40.1347) and Blackstone Dr (40.1365–40.1375), plus Clubview Blvd, which reaches
   Olentangy River Rd at −83.0367. **Core extent: lat 40.1223–40.1376, lng −83.0610 to
   −83.0367.**
2. **US Census Geocoder** (second source) placed real addresses on those streets within
   about 30 m of the OSM ways: 1221 Candlewood Dr (40.12314, −83.05157), 920 Clubview
   Blvd S (40.12474, −83.04227), 800 Blind Brook Dr (40.12927, −83.04397), plus batch
   matches on Blackstone Dr (40.1376, −83.0595), Shelley Ct (40.1334, −83.0602), Mission
   Hills Ln (40.1268–40.1271), Newcomer Rd (40.1347) and Briarmeadow Dr (40.1207). All
   are ZIP 43235.
3. **Padding.** About 500 m on every side (0.0045° lat ≈ 500 m; 0.006° lng ≈ 510 m at this
   latitude). North is stretched to 40.1450 to take in Loch Lomond Dr, Churchill Dr and
   Strathshire Hall (up to about Jewett Rd), which may belong to the neighborhood. A
   false "outside" would block a real neighbor; a false "inside" only reaches the admin's
   approval queue. The south edge sits just north of Hard Rd; the west edge is just
   east of Smoky Row Rd; the east edge runs past Olentangy River Rd into the river
   corridor.

To change it (no migration needed): `GEOFENCE=40.1175,40.1450,-83.0670,-83.0305` in the
env file, then `npm run contest-admin -- --contest lights`. The user should eyeball the
box on a map (e.g. paste the four corners into Google Maps) and widen it if any
Worthington Hills street falls outside.

## Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| Hosted `db push` fails or the API breaks because `lights` is exposed in the dashboard **before** the migration runs (PostgREST can't load a missing schema, same as D23, and that would take the parade's API down). | Medium if done out of order | Rollout order: **push first, then expose** the schema. Spelled out in "Hosted rollout notes". |
| The geofence is wrong and blocks a real neighbor. | Medium | Generous padding; the box is in settings and changes with one `contest-admin` command; the user confirms before Nov 28. |
| The address dedupe misses a variant (e.g. "Apt 2", a typo). | Medium, low impact | The admin reviews every entry and can hide or delete duplicates. One house per phone already limits abuse. |
| Census Geocoder is down or slow on submission day. | Low | 8 s timeout → 502 `geocoder_unavailable`; GPS is the primary signal (plan §4); the user can still drag the pin manually. |
| The in-memory rate limit doesn't hold across isolates. | Certain, low impact | Callers must be phone-verified, and Census is free and keyless; the limit only stops runaway loops. |
| Owners upload many photos while submissions are open (storage abuse). | Low | Phone-verified only, 10 MiB cap, image types only, own folder only; the admin can delete. Revisit in M8 if needed. |
| A late entry submitted after voting opens can't be edited by its owner. | Certain (by design) | Matches plan §4: owners are locked once voting opens. The admin can edit. M5 copy must say so before submitting. |
| `submitted_by` is publicly readable on approved houses. | Accepted | Opaque uuid, no phone; needed for "Your house" (D25). |
| An existing local stack fails to start after pulling M3. | Certain on old volumes | `stop --no-backup` (D23), in the README. |
| The edge runtime can't reach Census in sandboxes with TLS interception. | Certain here | Stub via `CENSUS_GEOCODER_URL` (D19); unit tests cover the parsing. |
| Seeded auth users interfere with the parade's local flows or M2's parity harness. | Low | Verified: OTP sign-in, the admin users API and the password grant work for the seeded 0101/0103; the admin phone isn't seeded. |

**Rollback:** revert the M3 merge on `main` through a PR. Locally, `supabase db reset`
then drops everything lights. Nothing reaches hosted until the user runs the rollout;
hosted rollback SQL is below.

**Houses** (`lights.houses`):
- Gallery/map: `from('houses').select('id, entry_number, title, address, lat, lng, photo_url, submitted_by').eq('status', 'approved')`.
  **Always filter `status`**: the admin's select returns every house.
- My entry: `.select('*').eq('submitted_by', session.user.id).maybeSingle()` (any status).
- Submit (M5): `prepareImageForUpload(file)` →
  `uploadPublicImage(client, { bucket: 'houses', path: `${uid}/${Date.now()}-${crypto.randomUUID()}.jpg`, … })` →

  Never send `status`, `submitted_by`, `id` or timestamps (column grants reject them).
  Paths must be new every time (no `upsert`). Errors: see D26.
- Edit (M5, before voting): `update({...}).eq('id', id).select()`. An empty array means

- Admin (M5): `update({ status: 'approved' | 'hidden' | 'pending' })`, edit any field at

  updating `photo_url` (the admin is exempt from the folder rule), `delete()` (cascades
  votes; prefer hide).

## Appendix A: migrations

### A.1: `supabase/migrations/20261113000000_lights_schema.sql`

```sql
-- Holiday lights contest: its own `lights` schema in the shared project.
--
-- This migration only creates objects inside `lights`. The parade's `public`
-- objects are untouched; the one shared object, public.is_admin(), is only
-- called from here.
--
-- Fairness model (same contract as the parade, see packages/core/README.md):
--   * Phone-verified users only (Supabase phone OTP); one house per phone
--     (unique houses.submitted_by) and one vote per phone (votes PK user_id).
--   * Every window is evaluated against the database clock inside RLS.
--   * Entries are pending until the admin approves them; only approved houses
--     are public and only approved houses can receive votes. No self-votes.
--   * Owners can edit or withdraw only before voting opens.
--   * Tallies are readable only through get_results(), only after the reveal,
--     and only for the top 3.

create schema lights;

-- Later migrations' objects in this schema get the same baseline: full access
-- for the service role, nothing for anon/authenticated until a migration
-- grants it explicitly. (Per-schema default privileges can only add, so the
-- global PUBLIC execute on functions is revoked explicitly at the end.)
alter default privileges in schema lights grant all on tables to service_role;
alter default privileges in schema lights grant all on sequences to service_role;
alter default privileges in schema lights grant execute on functions to service_role;

grant usage on schema lights to anon, authenticated, service_role;

-- Settings ---------------------------------------------------------------------
-- Single row (the check on id makes a second row impossible). Written only by
-- the service role (tools/contest-admin.mjs) or SQL; readable by everyone.
--
-- Defaults are the decided 2026 dates (America/New_York, EST = -05:00):
--   submissions Nov 28 – Dec 15 (closes at the end of Dec 15),
--   voting      Dec 8  – Dec 20 (closes at the end of Dec 20).
-- Geofence (FOR THE USER TO CONFIRM): Worthington Hills, Columbus OH 43235.
-- The parade's streets (Candlewood, Mission Hills, Blind Brook, Shelley /
-- Tennyson, Newcomer / Copperfield / Markhaven, Blackstone) and the Worthington
-- Hills Country Club span lat 40.1223..40.1376, lng -83.0610..-83.0367 in
-- OpenStreetMap (Overpass/Nominatim, © OpenStreetMap contributors, ODbL); the
-- US Census geocoder places addresses on those streets within ~30 m of that.
-- Padded ~500 m (north to 40.1450 to take in Loch Lomond, Churchill and
-- Strathshire Hall). See docs/milestones/M3.md "Geofence". Change it with
-- `contest-admin --contest lights` (GEOFENCE=...), not in a migration.
create table lights.settings (
  id boolean primary key default true check (id),
  voting_open boolean not null default true,          -- kill switch
  results_visible boolean not null default false,     -- the reveal
  voting_opens_at timestamptz,
  voting_closes_at timestamptz,
  submissions_open boolean not null default true,     -- kill switch
  submissions_open_at timestamptz,
  submissions_close_at timestamptz,
  geofence_min_lat double precision not null,
  geofence_max_lat double precision not null,
  geofence_min_lng double precision not null,
  geofence_max_lng double precision not null,
  constraint voting_window_valid check (
    voting_opens_at is null or voting_closes_at is null or voting_opens_at < voting_closes_at
  ),
  constraint submission_window_valid check (
    submissions_open_at is null or submissions_close_at is null
    or submissions_open_at < submissions_close_at
  ),
  constraint geofence_valid check (
    geofence_min_lat between -90 and 90 and geofence_max_lat between -90 and 90
    and geofence_min_lng between -180 and 180 and geofence_max_lng between -180 and 180
    and geofence_min_lat < geofence_max_lat and geofence_min_lng < geofence_max_lng
  )
);

insert into lights.settings (
  id,
  submissions_open_at, submissions_close_at,
  voting_opens_at, voting_closes_at,
  geofence_min_lat, geofence_max_lat, geofence_min_lng, geofence_max_lng
) values (
  true,
  '2026-11-28 00:00:00-05', '2026-12-16 00:00:00-05',
  '2026-12-08 00:00:00-05', '2026-12-21 00:00:00-05',
  40.1175, 40.1450, -83.0670, -83.0305
);

-- Window helpers -----------------------------------------------------------------
-- A null bound means "no restriction on that side" (same as the parade).
-- security invoker: settings is world-readable, so no definer is needed.

create function lights.submissions_are_open()
returns boolean
language sql
stable
set search_path = ''
as $$
  select s.submissions_open
     and (s.submissions_open_at is null or now() >= s.submissions_open_at)
     and (s.submissions_close_at is null or now() < s.submissions_close_at)
  from lights.settings s
$$;

create function lights.voting_is_open()
returns boolean
language sql
stable
set search_path = ''
as $$
  select s.voting_open
     and (s.voting_opens_at is null or now() >= s.voting_opens_at)
     and (s.voting_closes_at is null or now() < s.voting_closes_at)
  from lights.settings s
$$;

-- The edit lock. Owners may edit or withdraw only while submissions are open
-- AND the scheduled voting start is still in the future. It follows the
-- clock, not the voting_open kill switch, so pausing voting never unlocks
-- edits. A null voting_opens_at means voting is unrestricted from the start,
-- so owners are locked (fail closed).
create function lights.owner_edits_allowed()
returns boolean
language sql

-- Address dedupe key. Lowercase; keep only the street line (text before the
-- first comma); drop a trailing city/state/ZIP typed without commas; strip
-- punctuation and unit markers; abbreviate common suffixes and directions.
-- "1221 Candlewood Drive, Columbus, OH 43235" and "1221 candlewood dr."
-- both become "1221 candlewood dr". Immutable, so it can back a generated
-- column.
create function lights.normalize_address(p_address text)
returns text
language plpgsql
immutable
strict
parallel safe
set search_path = ''
as $$
declare
  abbreviations constant text[] := array[
    'drive', 'dr', 'court', 'ct', 'road', 'rd', 'lane', 'ln', 'street', 'st',
    'avenue', 'ave', 'boulevard', 'blvd', 'place', 'pl', 'circle', 'cir',
    'trail', 'trl', 'terrace', 'ter', 'parkway', 'pkwy',
    'north', 'n', 'south', 's', 'east', 'e', 'west', 'w'
  ];
  k text := lower(split_part(p_address, ',', 1));
begin
  k := btrim(regexp_replace(regexp_replace(k, '[^a-z0-9]+', ' ', 'g'), '\s+', ' ', 'g'));
  k := regexp_replace(
    k, '( (columbus|worthington|powell))?( (oh|ohio))?( [0-9]{5}( [0-9]{4})?)?$', '');
  for i in 1 .. array_length(abbreviations, 1) by 2 loop
    k := regexp_replace(k, '\m' || abbreviations[i] || '\M', abbreviations[i + 1], 'g');
  end loop;
  return btrim(k);
end;
$$;

-- Guards what RLS can't express (it can't compare old and new values):
--   * only the admin (or the service role / SQL) changes `status`;
--   * an owner's change to anything the public sees (address, pin, photo,
--     title) sends the entry back to `pending` for re-approval;
--   * an owner's photo_url must point into their own folder of the `houses`
--     bucket whenever it is set or changed;
--   * timestamps are server-set.
-- Runs as the caller (security invoker), so current_user tells API callers
-- (anon/authenticated) apart from the service role and migrations.
create function lights.houses_before_write()
returns trigger
language plpgsql
set search_path = ''
as $$
declare
  is_api_user constant boolean := current_user in ('anon', 'authenticated');
  trusted constant boolean := not is_api_user or public.is_admin();
begin
  if tg_op = 'INSERT' then
    new.created_at := now();
    new.updated_at := now();
    if not trusted then
      new.status := 'pending';
    end if;
  else
    new.created_at := old.created_at;
    new.updated_at := now();
    if new.status is distinct from old.status and not trusted then
      raise exception 'only the admin can change an entry''s status'
        using errcode = '42501';
    end if;
    if not trusted and (
      new.address, new.lat, new.lng, new.photo_url, new.title
    ) is distinct from (
      old.address, old.lat, old.lng, old.photo_url, old.title
    ) then
      new.status := 'pending';
    end if;
  end if;

  if not trusted
     and (tg_op = 'INSERT' or new.photo_url is distinct from old.photo_url)
     and position(
       '/storage/v1/object/public/houses/' || (select auth.uid())::text || '/'
       in new.photo_url
     ) = 0 then
    raise exception 'photo_url must be a photo you uploaded to the houses bucket'
      using errcode = '42501';
  end if;

  return new;
end;
$$;

create trigger houses_before_write

-- Results ------------------------------------------------------------------------
-- The only way to read tallies: nothing until results_visible, then the top 3
-- approved houses. Votes on hidden or pending houses never count and those
-- houses never appear. Ties break on entry_number (earlier entry first), the
-- same rule as the parade. search_path is empty and the body fully qualified.
create function lights.get_results()
returns table (
  house_id uuid,
  entry_number int,
  title text,
  address text,
  photo_url text,
  vote_count bigint,
  rank bigint
)
language sql
security definer
set search_path = ''
stable
as $$
  select r.id, r.entry_number, r.title, r.address, r.photo_url, r.vote_count,
         row_number() over (order by r.vote_count desc, r.entry_number) as rank
  from (
    select h.id, h.entry_number, h.title, h.address, h.photo_url,
           count(v.user_id) as vote_count
    from lights.houses h
    left join lights.votes v on v.house_id = h.id
    where h.status = 'approved'
      and (select s.results_visible from lights.settings s)
    group by h.id
  ) r
  order by r.vote_count desc, r.entry_number
  limit 3;
$$;
```

```sql
--   submissions:        submissions open, voting opens tomorrow (owners can edit)
--   overlap:            submissions still open, voting open (edits locked)

begin

    submissions_open = true,
    voting_open = true,
    submissions_open_at = case p_phase
      when 'before_submissions' then now() + interval '1 day'
      else now() - interval '10 days' end,
    submissions_close_at = case p_phase
      when 'before_submissions' then now() + interval '20 days'
      when 'submissions' then now() + interval '10 days'
      when 'overlap' then now() + interval '1 day'
      else now() - interval '1 day' end,
    voting_opens_at = case p_phase
      when 'before_submissions' then now() + interval '10 days'
      when 'submissions' then now() + interval '1 day'
      when 'closed' then now() - interval '9 days'
      else now() - interval '1 hour' end,
    voting_closes_at = case p_phase
      when 'closed' then now() - interval '1 hour'
      else now() + interval '30 days' end
  where id;
```

```ts
// Pure helpers for the geocode Edge Function. No Deno or network APIs here, so
// vitest (root `npm test`) can import this file directly.

export interface Geofence {
  minLat: number
  maxLat: number
  minLng: number
  maxLng: number
}

export interface GeocodeMatch {
  lat: number
  lng: number
  /** The Census Bureau's normalized address, e.g. "1221 CANDLEWOOD DR, COLUMBUS, OH, 43235". */
  matchedAddress: string
}

export const CENSUS_DEFAULT_BASE = 'https://geocoding.geo.census.gov'

/** Worthington Hills is all ZIP 43235 (Columbus). Appended when the user typed no ZIP. */
export const DEFAULT_LOCALITY = 'Columbus, OH 43235'

/** The Census API rejects one-line addresses longer than 100 characters. */
const CENSUS_MAX_CHARS = 100
const MIN_CHARS = 5

/**
 * Validates the request body and returns the one-line address to send to the
 * Census geocoder, or null if it isn't usable. Requires a house number (a
 * digit). Adds the default locality when no 5-digit ZIP is present.
 */
export function toCensusAddress(body: unknown): string | null {
  if (typeof body !== 'object' || body === null) return null
  const raw = (body as { address?: unknown }).address
  if (typeof raw !== 'string') return null
  // Collapse whitespace and drop control characters.
  // eslint-disable-next-line no-control-regex
  const address = raw.replace(/[\u0000-\u001f\u007f]+/g, ' ').replace(/\s+/g, ' ').trim()
  if (address.length < MIN_CHARS || !/\d/.test(address)) return null
  const full = /\b\d{5}(?:-\d{4})?\b/.test(address) ? address : `${address}, ${DEFAULT_LOCALITY}`
  return full.length <= CENSUS_MAX_CHARS ? full : null
}

export function censusUrl(oneLineAddress: string, base = CENSUS_DEFAULT_BASE): string {
  const url = new URL('/geocoder/locations/onelineaddress', base)
  url.searchParams.set('address', oneLineAddress)
  url.searchParams.set('benchmark', 'Public_AR_Current')
  url.searchParams.set('format', 'json')
  return url.toString()
}

export function inGeofence(point: { lat: number; lng: number }, box: Geofence): boolean {
  return (
    point.lat >= box.minLat && point.lat <= box.maxLat && point.lng >= box.minLng && point.lng <= box.maxLng
  )
}

/**
 * Picks the best match from a Census response: the first match inside the
 * geofence, else the first match. Returns null for no matches. Throws if the
 * payload isn't the documented shape (the caller maps that to a 502).
 */
export function pickMatch(payload: unknown, box: Geofence): GeocodeMatch | null {
  const matches = (payload as { result?: { addressMatches?: unknown } })?.result?.addressMatches
  if (!Array.isArray(matches)) throw new Error('unexpected Census response')
  const parsed: GeocodeMatch[] = matches.flatMap((m) => {
    const x = m?.coordinates?.x
    const y = m?.coordinates?.y
    if (typeof x !== 'number' || typeof y !== 'number' || typeof m?.matchedAddress !== 'string') return []
    return [{ lat: y, lng: x, matchedAddress: m.matchedAddress }]
  })
  return parsed.find((m) => inGeofence(m, box)) ?? parsed[0] ?? null
}

/** Settings row (snake_case columns) to a Geofence; null if any bound is missing. */
export function toGeofence(row: unknown): Geofence | null {
  const r = row as Record<string, unknown> | null
  const box = {
    minLat: r?.geofence_min_lat,
    maxLat: r?.geofence_max_lat,
    minLng: r?.geofence_min_lng,
    maxLng: r?.geofence_max_lng,
  }
  return Object.values(box).every((v) => typeof v === 'number') ? (box as Geofence) : null
}

/**
 * Sliding-window limiter keyed by user id. Per isolate, so it is best effort:
 * it stops a runaway client loop, not a determined attacker (who would still
 * need a phone-verified account).
 */
export class RateLimiter {
  private hits = new Map<string, number[]>()
  constructor(
    private readonly limit: number,
    private readonly windowMs: number,
  ) {}

  /** Records a hit; returns 0 when allowed, else the seconds to wait. */
  take(key: string, now = Date.now()): number {
    const recent = (this.hits.get(key) ?? []).filter((t) => now - t < this.windowMs)
    if (recent.length >= this.limit) {
      this.hits.set(key, recent)
      return Math.ceil((recent[0] + this.windowMs - now) / 1000)
    }
    recent.push(now)
    this.hits.set(key, recent)
    if (this.hits.size > 10_000) this.hits.clear() // bound memory on a long-lived isolate
    return 0
  }
}
```

```ts
// say whether it falls inside the contest geofence. Used by the lights
// submission flow when device GPS is denied (plan §4).
//
//   POST /functions/v1/geocode
//   Authorization: Bearer <signed-in user's access token>

//   404 { "error": "no_match" }

//   500 { "error": "geofence_unavailable" }    (lights.settings unreadable)

// The database re-checks the geofence on insert (RLS); this check is for UX.
// verify_jwt is off (config.toml) and the caller is verified here against
// GoTrue instead, which works with both legacy JWT keys and the new API keys.
//
// Env (set automatically by Supabase): SUPABASE_URL, SUPABASE_ANON_KEY.
// Optional: CENSUS_GEOCODER_URL to point at a stub in tests.

  CENSUS_DEFAULT_BASE,
  RateLimiter,
  censusUrl,
  inGeofence,
  pickMatch,
  toCensusAddress,
  toGeofence,
} from './census.ts'

  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
  'Access-Control-Allow-Methods': 'POST, OPTIONS',
  'Access-Control-Max-Age': '86400',

const SUPABASE_URL = Deno.env.get('SUPABASE_URL') ?? ''
const ANON_KEY = Deno.env.get('SUPABASE_ANON_KEY') ?? ''
const CENSUS_BASE = Deno.env.get('CENSUS_GEOCODER_URL') || CENSUS_DEFAULT_BASE
const CENSUS_TIMEOUT_MS = 8000

// 20 lookups per user per 10 minutes is plenty for one submission.
const limiter = new RateLimiter(20, 10 * 60 * 1000)

function json(status: number, body: unknown, extra: Record<string, string> = {}): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { ...CORS, 'Content-Type': 'application/json', ...extra },
  })
}

/** The signed-in user's id, or null. Asks GoTrue, so the token is really verified. */
async function userIdFrom(req: Request): Promise<string | null> {
  const auth = req.headers.get('Authorization') ?? ''
  if (!auth.startsWith('Bearer ')) return null
  const res = await fetch(`${SUPABASE_URL}/auth/v1/user`, {
    headers: { Authorization: auth, apikey: ANON_KEY },
  })
  if (!res.ok) return null
  const user = await res.json().catch(() => null)
  return typeof user?.id === 'string' ? user.id : null
}

async function loadGeofence() {
  const res = await fetch(
    `${SUPABASE_URL}/rest/v1/settings?select=geofence_min_lat,geofence_max_lat,geofence_min_lng,geofence_max_lng`,
    { headers: { apikey: ANON_KEY, Authorization: `Bearer ${ANON_KEY}`, 'Accept-Profile': 'lights' } },
  )
  if (!res.ok) return null
  const rows = await res.json().catch(() => null)
  return Array.isArray(rows) ? toGeofence(rows[0]) : null
}

Deno.serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response(null, { status: 204, headers: CORS })
  if (req.method !== 'POST') return json(405, { error: 'method_not_allowed' })

  const userId = await userIdFrom(req)
  if (!userId) return json(401, { error: 'sign_in_required' })

  const wait = limiter.take(userId)
  if (wait > 0) return json(429, { error: 'rate_limited' }, { 'Retry-After': String(wait) })

  let body: unknown
  try {
    body = await req.json()
  } catch {
    return json(400, { error: 'invalid_json' })
  }
  const address = toCensusAddress(body)
  if (!address) return json(400, { error: 'invalid_address' })

  const box = await loadGeofence()
  if (!box) return json(500, { error: 'geofence_unavailable' })

  let payload: unknown
  try {
    const res = await fetch(censusUrl(address, CENSUS_BASE), {
      signal: AbortSignal.timeout(CENSUS_TIMEOUT_MS),
    })
    if (!res.ok) throw new Error(`Census responded ${res.status}`)
    payload = await res.json()
  } catch (error) {
    console.error('geocode: Census request failed', error)
    return json(502, { error: 'geocoder_unavailable' })
  }

  let match
  try {
    match = pickMatch(payload, box)
  } catch (error) {
    console.error('geocode: unexpected Census payload', error)
    return json(502, { error: 'geocoder_unavailable' })
  }
  if (!match) return json(404, { error: 'no_match' })
  return json(200, { match, inGeofence: inGeofence(match, box) })
})
```
