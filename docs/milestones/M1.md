# M1: Monorepo conversion — implementation spec

Status: **ready to implement.** Every question below has been decided. Read
`docs/holiday-lights-plan.md` (§1 and the M1 entry in §6) and the orchestration brief
first; this spec overrides the plan wherever they differ.

Throughout, `$S` means the scratchpad:

`$REPO` means `/home/user/wohills-fav-favorite`.

## Goal

Turn the repo into an npm-workspaces monorepo with the parade site moved, unchanged, to
`apps/parade`, while the live parade keeps deploying from Vercel through the root
`vercel.json`. After M1 a later milestone can add `apps/lights` and `packages/*` without
touching the parade's layout again.

Nothing a visitor can see changes. The production bundle is the same apart from Tailwind
no longer emitting five unused utilities it used to pick up from the README and docs
(see decision D11).

## In scope

- npm workspaces at the root (`apps/*`, `packages/*`).
- `git mv` of the parade app into `apps/parade`: `src/`, `public/`, `scripts/`,
  `index.html`, `vite.config.ts`, the three tsconfigs, `wrangler.jsonc`, `.env.example`.
- Root `tsconfig.base.json`, root solution `tsconfig.json`, shared root ESLint flat config.
- Splitting `package.json` into a root manifest and `apps/parade/package.json`, and
  updating `package-lock.json` in place with no version changes.
- The `vercel.json` bridge (`buildCommand`, `outputDirectory`, existing rewrite).
- README updates for the new layout and for where `.env` now lives.

## Out of scope

- **Hosting/DNS (milestone H, on hold).** No Vercel or Cloudflare dashboard changes, no
  `wrangler deploy`, no `vercel deploy/link/pull`. `vercel.json` and `.vercelignore` stay.
- **Shared packages (M2).** `packages/` is not created. No code is extracted, and no
  file under `apps/parade/src` changes.
- **`tools/contest-admin.mjs` (M3).** `set-voting-window.mjs` moves into
  `apps/parade/scripts/` byte-for-byte; M3 generalizes it.
- `supabase/` and anything database-related. It stays at the root, untouched.
- Adding `supabase` as a devDependency, Turborepo, CI workflows, Playwright tests.
- Any dependency upgrade.

## Appendix A: `compare-dist.mjs`

```js
// Usage: node compare-dist.mjs <baselineDist> <newDist> <appDir>
// Structural comparison of two Vite builds of the same app.
import { readFileSync, readdirSync, statSync } from 'node:fs'
import { join, relative } from 'node:path'
import { createHash } from 'node:crypto'

const [base, next, srcDir] = process.argv.slice(2)
const walk = (d) => readdirSync(d).flatMap((f) => {
  const p = join(d, f)
  return statSync(p).isDirectory() ? walk(p) : [p]
})
// Vite names assets <name>-<8 char hash>.<ext>; strip the hash to compare structure.
const norm = (p) => p.replace(/-[A-Za-z0-9_-]{8}(\.\w+)$/, '$1')
const index = (d) => new Map(walk(d).map((p) => [norm(relative(d, p)), p]))
const a = index(base), b = index(next)
let ok = true
const fail = (m) => { ok = false; console.log('FAIL', m) }
const sha = (p) => createHash('sha256').update(readFileSync(p)).digest('hex')

const ka = [...a.keys()].sort().join('\n'), kb = [...b.keys()].sort().join('\n')
if (ka !== kb) fail(`file sets differ:\n${ka}\n---\n${kb}`)
else console.log('ok   same file set:', [...a.keys()].sort().join(', '))

for (const [k, pa] of a) {
  const pb = b.get(k)
  if (!pb) continue
  if (k.endsWith('.css')) continue // compared below
  if (k === 'index.html') {
    const strip = (p) => readFileSync(p, 'utf8').replace(/-[A-Za-z0-9_-]{8}\.(js|css)/g, '.$1')
    if (strip(pa) !== strip(pb)) fail('index.html differs beyond asset hashes')
    else console.log('ok   index.html identical apart from asset hashes')
    continue
  }
  if (sha(pa) !== sha(pb)) fail(`${k} content differs`)
  else console.log(`ok   ${k} byte-identical`)
}

// CSS: Tailwind only emits utilities for class names it finds while scanning.
// The new build may drop utilities the old one picked up from repo docs, but
// it must not add any, and nothing it drops may be used by the app.
const cssKey = [...a.keys()].find((k) => k.endsWith('.css'))
const classes = (p) => new Set(
  [...readFileSync(p, 'utf8').matchAll(/\.((?:\\.|[\w-])+)/g)]
    .map((m) => m[1].replace(/\\(.)/g, '$1'))
    .filter((c) => !/^\d/.test(c)),
)
const ca = classes(a.get(cssKey)), cb = classes(b.get(cssKey))
const added = [...cb].filter((c) => !ca.has(c))
const dropped = [...ca].filter((c) => !cb.has(c))
if (added.length) fail(`new CSS has classes the baseline lacks: ${added.join(' ')}`)
const srcText = walk(srcDir)
  .filter((p) => /\.(tsx?|html|css)$/.test(p) && !/[\\/](dist|node_modules)[\\/]/.test(p))
  .map((p) => readFileSync(p, 'utf8')).join('\n')
const esc = (s) => s.replace(/[.*+?^${}()|[\]\\/]/g, '\\$&')
const used = dropped.filter((c) => new RegExp(`(^|[\\s"'\`])${esc(c)}($|[\\s"'\`])`, 'm').test(srcText))
if (used.length) fail(`dropped classes that the app uses: ${used.join(' ')}`)
if (!added.length && !used.length) console.log(`ok   CSS: ${added.length} added, ${dropped.length} dropped (unused by app): ${dropped.join(' ')}`)
process.exit(ok ? 0 : 1)
```

## Appendix B: `compare-lock.mjs`

```js
// Usage: node compare-lock.mjs <oldLock> <newLock>
// Fails if any installed package changed version or disappeared.
import { readFileSync } from 'node:fs'
const [oldP, newP] = process.argv.slice(2)
const a = JSON.parse(readFileSync(oldP, 'utf8')).packages
const b = JSON.parse(readFileSync(newP, 'utf8')).packages
let bad = 0
for (const k of Object.keys(a)) {
  if (k === '') continue
  if (!b[k]) { console.log('removed', k); bad++ }
  else if (a[k].version !== b[k].version) { console.log('version', k, a[k].version, '->', b[k].version); bad++ }
}
for (const k of Object.keys(b)) if (!a[k] && k !== '') console.log('added  ', k)
console.log(bad ? `FAIL ${bad} changed` : 'ok   no installed package changed version')
process.exit(bad ? 1 : 0)
```
