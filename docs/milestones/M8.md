# M8: Launch hardening — implementation spec

Status: **draft, being written by the planning agent.** Sections below are filled in by
follow-up commits. Do not implement from this file until the status line says "ready to
implement".

## Goal

Everything that can be done locally to make the lights site launch-ready: the share image
and social meta, Playwright smoke tests for both apps in CI, an accessibility pass with axe,
the `contest-admin` runbook with a safe wipe (rehearsed against the local stack only), the
small follow-ups earlier reviews left, and a written operator checklist for every hosted step
(the agents never touch hosted Supabase, Vercel, Cloudflare or DNS).

## Decisions so far (to be expanded)

- Hosted items (expose `lights`, SMS limits, the hosted rehearsal) become an **operator
  checklist** in `docs/runbook-lights.md`, marked as not done by the agents.
- The rehearsal and the wipe are proven against the **local** stack only.
